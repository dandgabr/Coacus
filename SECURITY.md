# Security Policy

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/dandgabr/Coacus/security/advisories/new)
to send suspected vulnerabilities directly to the maintainers. The repository
must have private vulnerability reporting enabled for the form to accept
reports. The custom form is defined in
[`.github/VULNERABILITY_REPORT.yml`](.github/VULNERABILITY_REPORT.yml).

Do not report suspected vulnerabilities through public issues, discussions,
pull requests or other public channels. Do not include credentials, tokens or
personal data in a report. If the private report option is unavailable, contact
the maintainers through the [repository owner's GitHub profile](https://github.com/dandgabr)
and request a private reporting channel without disclosing technical details.

Include the affected Coacus revision or version, the relevant component and
configuration, the security impact, and steps or a proof of concept sufficient
to reproduce the issue safely. Please allow the maintainers to assess and
coordinate a fix before public disclosure; no response-time commitment is made.

If a credential may have been exposed, revoke or rotate it immediately as well
as reporting the incident privately.
