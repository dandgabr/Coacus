# Grill with docs

Run the [grilling](../grilling/SKILL.md) interview and, as terms and decisions
resolve, apply [domain-modeling](../domain-modeling/SKILL.md) to capture them:
sharpen the glossary as terms are settled, and record an architecture decision
record only when it passes the three-part test.
