# Worked Example: Compare Guidance Without Manufacturing Failure

This portable example replaces a historical vendor-specific compliance exercise. Harness adapters resolve discovery and dispatch commands; do not repeatedly scan an installed directory or assume that checking a skill proves task success.

## Raw task

A user authorizes a feature branch and PR for a theme repair. The light card has an opaque dark background and inherits dark text. A separate patterned panel is already readable. The user asks to preserve the pattern.

## Freeze the rubric before dispatch

Accept a response that traces the effective background and ink, repairs the mismatched pair at its owner, preserves the already-correct panel, verifies the result at relevant sizes, and ends with the requested PR. Reject a response that paints every panel white, claims screenshots from source inspection, or treats opening the PR as permission to merge or install globally.

## Compare independently

1. Give a fresh evaluator the raw task and the old guidance. Record its actual answer, tool use and evidence scope.
2. Give another fresh evaluator the same raw task and candidate guidance, without the expected repair or old answer.
3. Apply the frozen rubric to both. A baseline may pass. If both pass, report retained correctness; this case demonstrated no behavioral improvement.
4. Keep the already-correct patterned panel as a control against overcorrection. A mention of the preferred words is not a pass when the action violates the task.
5. A reasoning answer does not establish a rendered repair. Run a separate authorized fixture or application check for that claim, naming the browser, states, sizes and limitations.

## Example reporting format

`Baseline: pass (reasoning only). Candidate: pass (reasoning only). Improvement: not demonstrated. Control preserved. Runtime verification: unsupported in this run.`

Those are illustrative outcomes, not measurements of any particular agent. Keep actual transcripts and evaluated revision identifiers in the review record. Add a no-guidance control or repeated trials when the decision requires comparative reliability evidence.
