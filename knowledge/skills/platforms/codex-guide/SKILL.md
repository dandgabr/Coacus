# Codex Guide

Use the official skills documentation to choose scope, discover skills and check invocation. Confirm the active workspace and configuration rather than assuming another harness shares its settings.

Consult the [official documentation](https://learn.chatgpt.com/docs/build-skills) for current behavior before advising or changing configuration. Preserve existing configuration and obtain consent before installing or replacing files. Report unverified behavior as unverified.
