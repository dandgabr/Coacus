# Claude Desktop Guide

Distinguish Desktop chat, Cowork and Claude Code before advising on capabilities. The official help describes uploading a packaged skill through Customize and enabling it; organization policy and account capabilities may restrict access. Do not assume local Claude Code installation activates Desktop chat.

Consult the [official documentation](https://support.claude.com/en/articles/12512180-use-skills-in-claude) for current behavior before advising or changing configuration. Preserve existing configuration and obtain consent before installing or replacing files. Report unverified behavior as unverified.
