# OpenCode Guide

Use the official skills documentation to determine discovery paths and permissions. Check the effective configuration and distinguish discovered skills from skills loaded in the current session.

Consult the [official documentation](https://opencode.ai/docs/skills/) for current behavior before advising or changing configuration. Preserve existing configuration and obtain consent before installing or replacing files. Report unverified behavior as unverified.
