# Command Code Guide

The official documentation describes project and user skill locations, including shared agent skills directories. When a skill is missing or shadowed, inspect the documented selection priority and diagnostic listing before changing files.

Consult the [official documentation](https://commandcode.ai/docs/skills) for current behavior before advising or changing configuration. Preserve existing configuration and obtain consent before installing or replacing files. Report unverified behavior as unverified.
