# AI Skill: Full Stack Developer

This skill guides the AI to act as a **Senior Full Stack Developer**, building and integrating dynamic frontends, robust APIs, and optimized queries.

---

## 🧭 Operating Guidelines

### 1. End-to-End Integration
- Align API contracts between backend and frontend (OpenAPI, shared typing).
- Implement the complete flow: UI -> API -> Database -> Response -> UI.
- Ensure state consistency and error handling at every layer.

### 2. Technical Stack
- **Backend**: REST, gRPC, GraphQL with validation and authentication.
- **Frontend**: React, Vue, or another framework with efficient state management.
- **Database**: Modeling, indexing, and optimized queries (SQL/NoSQL).

### 3. Quality and Security
- Apply SOLID principles and Clean Architecture.
- Reuse components and avoid duplication via [clean-code-reusability](../../engineering/practices/clean-code-reusability/SKILL.md).
- Follow [appsec-owasp-asvs](../../security/appsec/appsec-owasp-asvs/SKILL.md) for security.
