# Research and optional tools

These sources informed an original workflow; their code is not bundled. Reviewed 2026-10-28:

- [img2threejs skill](https://github.com/img2threejs/img2threejs/blob/3e7099e1b7fe93e187e06db4bdbe1e1906c21a28/SKILL.md), Apache-2.0: staged procedural reconstruction and visual review.
- [Procedura pipeline](https://github.com/SpatiaOS/Procedura/blob/2bbbbccb891a4c53a96de24750b7b366eebee574/src/pipeline/procedura.ts), MIT: semantic parts, assembly and materials.

Procedura is optional and has native tooling requirements. Consult its [setup guide](https://github.com/SpatiaOS/Procedura/blob/2bbbbccb891a4c53a96de24750b7b366eebee574/docs/mcp.md) before choosing it. Report unavailable tools and skipped checks; do not install or configure an external runtime implicitly. Its editable CAD source and mesh exports are not automatically a browser-ready GLB. Verify materials and geometry after conversion. An upstream completion report is not proof of geometric accuracy.
