# UI Style: Weirdcore & Liminal Dreamcore

An internet-native surrealist aesthetic centering on liminal spaces, forgotten 1990s/2000s digital photography, low-fidelity amateur editing, and psychological dreamscapes. Evokes a paradoxical mix of uncanny unease and childlike nostalgia.

---

## 🧭 When to Activate

- Indie horror and psychological mystery games, surrealist web experiences, music albums, and conceptual digital poetry.
- Evoking intimate, dreamlike, or unsettling atmospheric tension.

---

## 🎨 Visual DNA

- **Palette:** Faded flash-photography tones, overcast sky beige (`#D9D5C7`), fluorescent institution green (`#A8C5A0`), deep void black (`#0A0A0A`), and saturated cherry red.
- **Type:** Low-res pixel fonts, standard Arial/Times New Roman with red drop shadows, cryptic centered poetic phrases.
- **Visuals:** Empty carpeted hallways, suburban playgrounds at dusk, low-resolution JPG compression halo artifacts, red glowing text boxes.

---

## 🛠️ Implementation Notes

```css
.liminal-card {
  background: #111;
  border: 1px solid #444;
  color: #d9d5c7;
  font-family: 'Times New Roman', serif;
  box-shadow: 0 0 15px rgba(255, 0, 0, 0.2);
}
```

---

## ♿ Accessibility

- The aesthetic relies on disorientation, but critical UI navigation must remain accessible, semantic, and high contrast.
