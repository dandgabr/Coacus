# Canvas Spatial Whiteboarding: Visual Research & Strategic Discovery

An infinite canvas is a cognitive workspace for synthesis, sensemaking, and architectural discovery. Grounded in spatial cognition (Tversky, 2011) and information mapping theory, visual arrangement transforms abstract, high-dimensional trade-offs into **navigable, relational artifacts**. The deliverable of a whiteboard is structured understanding for decision-making, not a finished production layout.

---

## 🧭 When to Activate

- Conducting competitive research, feature breakdowns, and vendor trade-off analyses.
- Synthesizing unstructured user interviews into affinity clusters and theme maps.
- Mapping end-to-end user journeys (User Story Maps, Service Blueprints, Interaction Trees).
- Facilitating technical architectural discovery before writing specification documents.
- Structuring meeting briefs, brainstorm agendas, and multi-option design trade-offs.

---

## 🗺️ Spatial Information Architecture

An infinite canvas easily descends into visual noise without intentional zoning. Divide the infinite plane into structured spatial coordinates:

```
  (-X, +Y) [DISCOVERY & BENCHMARK]      |  (+X, +Y) [SYNTHESIS & FRAMEWORKS]
  - Competitor Screenshots              |  - 2x2 Positioning Matrices
  - Live Browser Snapshots              |  - User Journey Flows
  - Unfiltered Notes & Raw Data         |  - Feature Breakdown Tables
  --------------------------------------+-----------------------------------
  (-X, -Y) [DECISION MATRIX]            |  (+X, -Y) [DELIVERABLES & ROADMAP]
  - Architecture Trade-Offs             |  - Wireframe Flows (Lo-Fi)
  - Open Questions & Parking Lot        |  - Action Items, Owners & Deadlines
  - Go / No-Go Decision Criteria        |  - Technical Spec Outlines
```

### Canvas Hygiene Rules
1. **Named Frames**: Group related artifacts into distinct bounded frames with explicit titles (`H1` level, e.g., `FRAME: Competitor Checkout Analysis`).
2. **Left-to-Right Narrative Chronology**: Arrange board flows from left (Context / Problem) to right (Synthesis / Solution).
3. **Color-Coded Semantic Sticky Notes**:
   - 🟡 **Yellow**: Observations, user feedback, factual notes.
   - 🟢 **Green**: Opportunities, strengths, confirmed decisions.
   - 🔴 **Red / Pink**: Pain points, critical risks, blockers.
   - 🔵 **Blue**: Functional requirements, user tasks, roadmap items.

## 📊 Core Analytical Whiteboard Frameworks

### 1. The 2×2 Competitive Positioning Matrix
- **Geometry**: Two intersecting perpendicular axes defining polar spectrums (e.g., `Simplicity vs Deep Configurability` on X, `Self-Hosted vs Managed Cloud` on Y).
- **Execution**:
  - Place competitor logos / screenshots into the four quadrants.
  - Highlight the "Blue Ocean" or differentiated strategic position for your product with an accentuated boundary frame.
  - Annotate key strengths and failure modes directly adjacent to each competitor cluster.

### 2. User Journey Mapping & Service Blueprints
- **Horizontal Axis**: Sequential phases of the user lifecycle (e.g., `Discovery → Onboarding → First Value → Expansion → Churn Risk`).
- **Vertical Swimlanes**:
  - **Lane 1: User Actions**: What the user does at each step.
  - **Lane 2: Touchpoints & UI**: Interfaces, emails, API calls encountered.
  - **Lane 3: Emotional Curve & Thoughts**: Frustrations, doubts, "Aha!" moments.
  - **Lane 4: Behind-The-Scenes Systems**: Backend workers, database triggers, third-party webhooks.

### 3. Affinity Clustering (KJ Technique)
- **Step 1: Brain Dump**: Generate individual atomic observation cards without premature categorization.
- **Step 2: Silent Grouping**: Move related notes into spatial proximity clusters based on semantic affinity.
- **Step 3: Cluster Framing**: Draw a bounding frame around each cluster and crown it with a bold summary statement (e.g., `Cluster: Friction during API Token Creation`).

### 4. Lo-Fi Wireframe Flows & Decision Trees
- **Structure**:
  - Use simple geometric frames (rectangle screens with basic headers, buttons, cards).
  - Connect screens with directional arrows showing explicit user triggers (`Click 'Connect Bank' → Loading Sheet → Success Screen`).
  - Add branch diamonds for conditional states (`If OAuth fails → Error Toast / Retry Modal`).

## 👥 Collaborative & Multiplayer Board Guidelines

In collaborative canvas environments (Figma/FigJam, Miro, Pencil):
1. **Viewport Anchoring**: Create a prominent "Start Here" banner at `(0, 0)` with a table of contents and board legend.
2. **Lock Static Scaffolding**: Lock background grids, swimlanes, and axis labels so contributors only interact with content nodes.
3. **Dedicated Parking Lot**: Keep a reserved frame for tangent ideas or unresolved debates to preserve meeting momentum without losing context.
