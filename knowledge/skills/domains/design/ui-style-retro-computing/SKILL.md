# UI Style: Retro Computing (Phosphor CRT, 80x25 Character Grid & BIOS Metaphors)

Retro Computing captures the direct physical experience of 1970s and 1980s microcomputers and video terminals: the DEC VT100, Apple II, IBM Personal Computer 5150 (MS-DOS), Commodore PET, and BBC Micro. Unlike modern minimalistic terminal emulators, Retro Computing models the optical and mechanical characteristics of the era: P1 green (`#33FF33`) or P3 amber (`#FFB000`) phosphor glow, scanlines, CRT screen convexity, 80x25 character matrix layouts, blinking block cursors (`█`), and ASCII/ANSI box-drawing characters (`┌─┐│└─┘`). Synthesized from vintage hardware engineering manuals; see Sources.

---

## 🧭 When to Activate

- Designing system diagnostic consoles, hardware emulators, developer tool interfaces, retro computing archives, or vintage hacking simulators.
- Implementing textual user interfaces that feel physically rendered on late-70s / early-80s display hardware.
- Distinct from **[ui-style-pixel-art](../ui-style-pixel-art/SKILL.md)**: Pixel Art focuses on video game sprites, animated game tiles, and 8/16-bit console palettes; Retro Computing focuses on personal computer operating environments, command prompts, BIOS menus, and ASCII grid data.
- Distinct from **[ui-style-terminal-tui](../ui-style-terminal-tui/SKILL.md)**: Modern TUI uses contemporary terminal styling; Retro Computing models vintage phosphor luminescence, CRT scanlines, and 80s microcomputer beige chassis framing.

---

## 🕰️ Definition, Lineage, and Timeline

- **Chronology:** The terminal era peaked between 1978 (DEC VT100, the first terminal with ANSI escape codes and cathode ray tube display) and 1981–1983 with the launch of the IBM PC 5150 running PC DOS.
- **Hardware Realities:** Text was addressed strictly in character cells (typically 80 columns by 25 rows) generated by a hardware character generator ROM. Phosphor persistent glow (P1 green, P3 amber, P4 white) left subtle ghosting after fast scrolling.

---

## 🎨 Visual DNA & Subgenre Taxonomy

- **Palettes:**
  - P1 Green Phosphor (`#33FF33` / `#00EE00` on deep screen black `#051005`)
  - P3 Amber Phosphor (`#FFB000` / `#E69500` on deep screen amber-black `#140A00`)
  - Classic IBM PC BIOS Blue (`#0000AA` background with `#AAAAAA` or `#FFFFFF` type)
  - Vintage Computer Chassis Beige (`#D9CEB8` / `#C8BEAA`)
- **ASCII & ANSI Box-Drawing Architecture:**
  - Windows and dialog containers drawn using classic character glyphs: single-line (`┌ ─ ┐ │ └ ─ ┘`) and double-line (`╔ ═ ╗ ║ ╚ ═ ╝`).
- **Typography:**
  - Authentic hardware bitmap fonts: Fixedsys, IBM VGA 8x16, VT323, Perfect DOS VGA, Glass TTY VT220.
  - Strict monospace rhythm: all elements conform to integer multiples of character cell width (e.g. 8px width × 16px height).
- **CRT Phosphor Physics:**
  - Micro-scanlines at 10% opacity, subtle phosphor bloom on active characters, and continuous blinking block cursor (`animation: blink 1s step-end infinite`).

## ✨ Micro-Interactions, Motion & Soundscapes

- **Blinking Cursor:** Rigid 1Hz square wave (`step-end`), completely un-eased.
- **Instantaneous Character Printing:** Transitions between states occur line-by-line with no opacity fades.
- **Phosphor Persistence Decay:** Fast scrolling leaves a faint 150ms green decay ghosting trail.

---

## 📱 Responsive Layout & Spatial Composition

- Maintain strict monospace alignment. If the screen width drops below 80 characters, wrap by word without breaking box-drawing glyph boundaries.

---

## ♿ WCAG 2.2 Accessibility & High-Contrast Guardrails

- **Contrast Ratios:**
  - P1 Green Phosphor (`#33FF33`) on CRT Background (`#061106`): **14.8:1** (Passes WCAG AAA).
  - P3 Amber Phosphor (`#FFB000`) on Dark Amber (`#140A00`): **11.2:1** (Passes WCAG AAA).
- **Reduced Motion:**
  ```css
  @media (prefers-reduced-motion: reduce) {
    .retro-cursor {
      animation: none;
      opacity: 1;
    }
    .retro-scanlines {
      display: none;
    }
  }
  ```

---

## 🚫 Anti-Patterns & Visual Sins (Anti-AI Slop Traps)

- ❌ **NEVER use rounded buttons or anti-aliased proportional sans-serifs:** Retro Computing requires rigid monospace typography.
- ❌ **NEVER use generic smooth pastel gradients:** Colors are discrete CRT phosphor emissions.
- ❌ **NEVER use 3D floating shadows:** All depth stems from CRT screen bezel framing.

---

## 🎯 When to Use & When to Avoid

- **Use For:** Hardware diagnostics, code compilers, cybersecurity sandboxes, retro gaming archives, vintage tech portals.
- **Avoid For:** Casual shopping sites, image-heavy fashion lookbooks, multi-media content platforms.
